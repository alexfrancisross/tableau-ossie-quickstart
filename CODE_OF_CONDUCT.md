# Code of Conduct

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be respectful, welcome different viewpoints, give and accept constructive feedback, and do not harass others.

To report unacceptable behavior, open a private report via GitHub (Security tab, "Report a vulnerability") or contact the maintainer [@alexfrancisross](https://github.com/alexfrancisross).
