# Contributing

This is a personal sample project, not an official Snowflake product. Contributions are welcome but responses are best effort.

## How to help
- Open an issue describing the problem or idea, with steps to reproduce and your Python and package versions.
- For a pull request, keep it small and focused, and explain what it changes and why.
- Do not include credentials, account identifiers, customer data or screenshots that show them. Use only public sample data such as `SNOWFLAKE_SAMPLE_DATA`.

## Security
Report vulnerabilities privately as described in [SECURITY.md](SECURITY.md), not in public issues.
